# ResQ — تطبيق إنقاذ ورعاية الحيوانات

تطبيق موبايل بالعربية يربط المبلّغين عن حالات الحيوانات المحتاجة بالجمعيات والعيادات البيطرية، ويتيح التبنّي والتبرّع ومتابعة نقاط الإطعام.

مشروع أكاديمي (PR1) — الجامعة الافتراضية السورية، دورة S25.

---

## ⚠️ حالة التكامل

التطبيق يعمل حالياً على **بيانات وهمية في الذاكرة**، ولم يُربط بعد بأي خادم خلفي.

المفتاح المركزي في `src/constants/config.ts`:

```ts
useMockApi: true
```

طالما هذه القيمة `true`، كل عمليات القراءة والكتابة تجري على مستودعات محلية في `src/data/repositories/`، وتُفقد البيانات عند إعادة تشغيل التطبيق. **هذا ليس مكافئاً لنسخة إنتاجية متصلة بخادم.**

تفاصيل حدّ التكامل وخطوات الانتقال للإنتاج: `PRODUCTION-READINESS.md`.

## التشغيل

```bash
npm install
npm run web        # تشغيل على المتصفح
npm start          # تشغيل Expo
```

الخريطة الأصلية تتطلب `GOOGLE_MAPS_API_KEY` ونسخة تطوير (dev build)؛ على الويب تُعرض معاينة ثابتة بديلة. انسخ `.env.example` إلى `.env` واضبط المفتاح.

## بنية المشروع

```
app/                  مسارات Expo Router — ربط المسار بالشاشة فقط
src/
  features/           الميزات: كل ميزة لها screens/ و components/ و hooks/
  components/ui/      المكوّنات المشتركة
  domain/             قواعد العمل، معزولة عن الواجهة
  application/        خدمات التنسيق بين النطاق والبيانات
  data/repositories/  المستودعات (وهمية حالياً)
  theme/              كل توكنز التصميم
  navigation/         تعريف المسارات
  i18n/               أدوات الاتجاه العربي
scripts/              فحوصات الجودة الآلية
```

## أنواع الحسابات

- **زائر** — تصفّح وإرسال بلاغ إنقاذ بدون تسجيل.
- **مستخدم** — بلاغات، تبنّي، تبرّع، نقاط إطعام، تطوّع.
- **جهة** — عيادة بيطرية أو جمعية إنقاذ، مع لوحة عمليات.

## ضمان الجودة

```bash
npm run typecheck    # فحص الأنواع
npm run lint         # فحص الأسلوب
npm run test         # اختبارات الوحدة
npm run check        # السلسلة الكاملة
```

⚠️ `npm run check` سلسلة طويلة مربوطة بـ `&&`، و`typecheck` و`lint` و`test` في آخرها — أي فشل يحجب كل ما بعده. عند التحقّق من عمل جديد، شغّل الثلاثة الأخيرة مباشرةً وبشكل منفصل.

## قواعد المساهمة

القواعد الملزمة للعمل على الكود موثّقة في **`CLAUDE.md`** — الالتزام بها إلزامي لكل من يعدّل المشروع (بشراً كان أم أداة).

باختصار: لا ألوان أو مسافات حرفية (كلها من `src/theme`)، استخدام المكوّنات المشتركة بدل إعادة بنائها، `start`/`end` بدل `left`/`right`، والمسارات في `src/navigation/routes.ts` حصراً.
